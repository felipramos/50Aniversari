✏️ Com editar la web

Fitxer principal: Tot el codi de la web és un únic fitxer index.html al repositori de GitHub. Per fer canvis, edita aquest fitxer i puja'l al repositori.

Passos per actualitzar la web

  • 1
    Ves a github.com/felipramos/50Aniversari i obre el fitxer index.html
  • 2
    Fes clic al llapis ✏️ per editar directament al navegador, o baixa el fitxer, edita'l i puja'l de nou
  • 3
    Desa els canvis amb Commit changes — la web s'actualitza en 1-2 minuts automàticament
  • 4
    Per veure els canvis en viu, ves a la URL pública i fes Ctrl+Shift+R (refresc forçat)

    Dedicatòries: Supabase → Table Editor → entries → Export CSV
  • 3
    ⚠️ Fes-ho abans dels 7 dies o reactiva el projecte a Supabase

🗃️ Queries SQL útils · Supabase

Gestió de continguts des del SQL Editor de Supabase

Veure tot el contingut
select * from entries order by id desc;
Esborrar totes les fotos
delete from entries where type = 'photo';
Esborrar totes les dedicatòries
delete from entries where type = 'dedication';
Esborrar tot
delete from entries;
